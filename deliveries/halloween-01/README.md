# 万圣节活动海报：分层重建说明

## 画布与文件

原尺寸 941 × 1672 像素，RGB。主要元素位置、文字内容和版式依照原图重建。

- recreated.psd：分组分层的 PSD。
- preview.png：默认显示图层的合成预览，与 PSD 的合并预览一致。
- layers/：各图层的全画布透明 PNG 缓存。
- layer_manifest.json：图层、原生文字、矢量填充与路径数据；顺序 bottom-to-top。
- masks/castle_fade.png：城堡下部渐隐蒙版。
- validation.json：PSD 结构回读及独立验证结果。

## 编辑结构

8 个分组、71 个内容图层：13 个原生文字层、42 个原生形状层、16 个位图层（含 1 个隐藏原图参考层）。

1. 夜空与环境：原生紫色渐变背景、原生小路形状、月光/晚霞/暗部光影及重建星尘。
2. 月亮城堡与装饰：月亮原生渐变形状、独立月面纹理；城堡、窗光、枯树、蝙蝠、星形与远景叶簇为原生轮廓形状。
3. 主体美术字：“万圣节”“狂欢派对”及下方弧线为原生轮廓形状，巫师帽与小南瓜为独立复杂插画位图。
4. 信息卡与原生图标：原生不规则纸卡、渐变标签、编号圆、虚线、时钟/定位/幽灵图标、蛛网及蜘蛛；纸张颗粒与暖色纹理独立。
5. 常规文字：品牌标识、活动内容标题、三条活动说明、三个编号、活动时间标题及正文、活动地点标题及正文、扫码报名，共 13 个可直接修改内容的原生文字层。品牌短线和扫码提示线为原生形状。
6. 前景插画：幽灵与巫师帽、主南瓜、提灯、右下双南瓜分别为独立透明位图；墓园围栏、枯叶和草丛为分区原生剪影。
7. 二维码：独立原尺寸位图，保持原位置、未重采样；包含其原始浅色底。
8. 原图参考：reference_hidden 默认隐藏，半透明，仅用于对齐，不参与交付预览。

除参考原图外，所有对象默认显示。原生文字/形状并非通过隐藏原图副本替代。

## 尚未拆分及近似重建范围

- 幽灵与大巫师帽在同一个独立位图中；帽带、脸、身体褶皱及局部高光未逐件拆分。
- 大南瓜的果肉、五官、瓜蒂及内部明暗在同一南瓜位图中。
- 提灯的金属框、玻璃与灯光仍在同一个位图中；右下两个南瓜仍组合在一层。
- 小巫师帽、小南瓜、二维码内部模块分别未进一步拆成零件。
- 蛛网和蜘蛛组合为一层原生路径；剪影叶簇和围栏为分区组合路径，未逐片叶子/每根栏杆拆分。
- 月面坑纹保留为独立纹理，没有逐个坑纹拆分。
- 美术字为可编辑路径轮廓，不是可直接替换文字内容的字体层。
- 背景星尘、小路、纸卡纹理、色彩与光影为近似重建，隐藏区域无法从单张图中恢复；整体不是逐像素复原。
- 插画轮廓蒙版、剪影细枝和字体边缘仍有可继续精修的局部。原生形状重绘与缓存预览可能存在抗锯齿差异。

## 字体

常规文字使用 Noto Sans CJK SC Regular / Bold（NotoSansCJKsc-Regular / NotoSansCJKsc-Bold），属于近似替代字体。字宽与字号已按原图布局调整。

PSD 不嵌入字体。编辑前请安装对应字体；替换字体可能改变字宽与排版。

## 二维码验证

二维码区域按原图像素逐点保留，没有重绘、修补或替换内容。

原始图片和导出预览均未能被 OpenCV 自动解码。因此只能确认像素保真，不能确认此二维码实际可扫或报名链接有效。如需可用报名码，请另提供经过验证的原始二维码或报名网址再替换。

## 验证范围

已用 ag-psd 回读尺寸、图层、原生文字、矢量填充和蒙版，确认只有参考图隐藏；PSD 合并预览与 preview.png 一致。另用 psd-tools 识别类型并重新渲染检查。未在桌面 Photoshop 内人工打开验证。
